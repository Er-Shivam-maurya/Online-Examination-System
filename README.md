Online Examination System

A web-based Online Examination System developed using Java, JSP, Servlet, JDBC, and MySQL. The application provides separate portals for Students, Examiners, and Admins to manage and conduct MCQ-based online examinations efficiently.

Features

- Student Registration and Login
- Examiner Registration and Login
- Admin Management Portal
- Subject-wise MCQ Examinations
- Question and Answer Management
- Automated Result Generation
- Session-Based Authentication
- MySQL Database Integration
- Responsive User Interface

Technologies Used

- Java
- JSP & Servlet
- JDBC
- MySQL
- HTML
- CSS
- Bootstrap
- Tailwind CSS
- Apache Tomcat
- WAMP Server

Modules

Student

- Register/Login
- Attempt Exams
- View Results
- Manage Profile

Examiner

- Create Exams
- Add Questions and Options
- Set Correct Answers
- Manage Question Bank

Admin

- Manage Students
- Manage Examiners
- Monitor System Activities
